# 🛒 OnlineShop - ASP.NET Core MVC E-commerce Solution

A modern, feature-rich e-commerce platform built with **ASP.NET Core MVC** and **SQL Server**. The application implements a clean separation between **Admin** and **User** areas using MVC Areas, providing a complete online shopping experience including product browsing, cart management, order placement, and administrative controls.

## ✨ Features

### 👤 User Area (Customer)
- **User Authentication & Registration** (Identity or Custom)
- **Product Catalog** - Browse products with filtering, sorting, and search
- **Product Details** - View detailed product information, images, and prices
- **Shopping Cart** - Add/remove items, update quantities, view cart summary
- **Checkout Process** - Place orders with shipping/billing information
- **Order Management** - View order history and order status
- **User Profile** - Manage personal details and saved addresses

### 👑 Admin Area
- **Secure Admin Dashboard** - Overview of sales, orders, and inventory
- **Product Management** - CRUD operations for products (add, edit, delete, manage stock)
- **Category Management** - Create and manage product categories
- **Order Management** - View all customer orders, update order status (Processing, Shipped, Delivered, Cancelled)
- **User Management** - View registered users, manage roles (Admin, Customer)
- **Sales Reports** - Generate reports on sales and revenue

### 🛠️ Core Functionality
- **SQL Server Database** - Robust data persistence with Entity Framework Core
- **Session-Based Cart** - Cart persists during user session (or logged-in persistence)
- **Responsive Design** - Works on desktop, tablet, and mobile devices
- **Role-Based Authorization** - Secure access to Admin area
